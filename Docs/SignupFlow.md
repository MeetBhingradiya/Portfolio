# Register & Signup Flow

### Case 1 : Fresh User
1. Enter Email
2. Basic Info (First Name, Last Name, DOB, Gender)
3. Enter Password
4. Verify Email
5. Create Username (Optional we Provide a default username using first name and last name)
6. Prompt for Gravatar Profile Picture Acsess
7. Redirect to Tools Page

### Case 2 : User with Email already registered but not verified
1. Enter Email
2. Enter Password
3. Verify Email
4. Create Username (Optional we Provide a default username using first name and last name)
5. Prompt for Gravatar Profile Picture Acsess
6. Redirect to Tools Page

### Case 3 : User with Email already registered and verified but not Username Created
1. Enter Email
2. Enter Password
3. Create Username (Optional we Provide a default username using first name and last name)
4. Prompt for Gravatar Profile Picture Acsess
5. Redirect to Tools Page

### Case 4 : User with Email already registered, verified and Username Created (Auto Login Flow)
1. Enter Email
2. Enter Password
3. Redirect to Tools Page
