# Assignment Document System - PDF Export from Just JSON,Image CDN Data

## Overview
- User Inputs a Data about the Assignment or Practical

Single Assignment Document will have the following Meta details:
- 1. Assignment No
- 2. Assignment Title
- 3. Student Name
- 4. Student Enrollment No
- 5. Assignment Creation Date (Auto Non Editable & Can be Hidden)
- 6. Assignment Date (IF Edited then use This otherwise use Creation Date)
- 7. Watermark (if enabled then show the watermark on the document)
- 8. Assignment Signature- Hash (Auto Generated & Made from MetaData only)
- 9. Privacy (Public, Unlisted or Private)
- 10. Assignment Description (Optional)
- 11. Assignment Subject (Optional)
- 12. Assignment Subject Code (Optional)

Data that can be Displayed in the Assignment Document:
- 1. Code Snippets (if any use syntax highlighting & Monaco Editor for better display)
- 2. Images (if any use the image CDN for Uploads & Display, @Reffer ./CDN_SYSTEM.md on this File Directory)
- 3. Code Blocks - A Block that Contains Text Line & its Desicription, then Code Snippet then Output Image or Generated Output Image of Terminal that Generated by the System, This Code Blocks can be Multiple in a Single Assignment Document
- 4. Steps Block - A Block that Contains Steps, A Counter no & its Description can be butted or Numbered Lists, or Even Image Uploads, This Steps Block can be Multiple in a Single Assignment Document
- 5. Tables - A Block that Contains a Table with its Description, This Tables can be Multiple in a Single Assignment Document
- 6. Text Blocks - A Block that Contains a Text with its Description, This Text Blocks can be Multiple in a Single Assignment Document

# Security Policies
- 1. The System will Generate a Unique Hash for Each Assignment Document, This Hash will be Generated from the Meta Data of the Assignment Document, This Hash will be Used for Verification of the Document, If the Hash is Changed then the Document is Considered as Tampered or Fake & can't be Opened or Viewed (Signature Hash)

- 2. Limites in the Number of Uploads of Images

- 3. Limites in the Size of the Images that can be Uploaded

- 4. Limites Blocks that can be Added in a Single Assignment Document to avioid Spam or Overloading of the System

## PDF Generation
- The System will Generate PDF from the Above Data, The PDF will be Generated in a Proper Format & Layouts can be Modified using Just Click on the UI

## Tool Listing & Management
- Tool will Listed as Custom Separate Dashboard and Listed Via /Settings & Manage to Enable to All the Users at /admin/features with Limits can be Modifiable by Admin

- Tool can be having below Permissons to Operate

Category 1 for Each Document Having Its Own Permissions:
1. Tools.AssignmentSystem.Edit - Permission to Edit Assignment Document
2. Tools.AssignmentSystem.Delete - Permission to Delete Assignment Document (Its Soft Delete, User can Restore it from Trash if Deleted by Mistake, Admin can Still Restore even User deleted from Trash)
3. Tools.AssignmentSystem.View - Permission to View Assignment Document (Considering the Privacy Settings of the Document)
4. Tools.AssignmentSystem.Share - Permission to Share Assignment Document with Others (Generate Shareable Link or Direct Sharing via Account Email or Username)
5. Tools.AssignmentSystem.Download - Permission to Download Assignment Document as PDF (Considering the Privacy Settings of the Document)

Category 2 for Overall System Permissions:
1. Tools.AssignmentSystem.Create - Permission to Create Assignment Document
2. Tools.AssignmentSystem.List - Permission to List All Assignment Documents (for Only Public Documents or Own Documents if Private)
3. Tools.AssignmentSystem.Manage - Ultimate Permission to Manage All Aspects of the Assignment Document System (Only for Admin, Can Override All Permissions & Access All Documents Regardless of Privacy Settings) also Grants to Restrict the Document Access to Admin Only even User is Owner of the Document, User can able to List this Document but can't Edit or View or Share or Download it, Only Admin can Access it, This is for Confidential Documents that User don't want to Share with Anyone Even if they are Owner of the Document, This Restriction can be Enabled or Disabled by Admin for Each Document Individually.
